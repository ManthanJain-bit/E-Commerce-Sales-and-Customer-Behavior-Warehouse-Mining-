Mining Scalability: Apriori explodes by 141× while FP-Growth stays fast
Execution time as the minimum support threshold drops from 5% down to 1% across 79,405 grocery baskets.
Key Algorithmic Finding:
• At 5% support: Both algorithms finish in under half a second.
• At 1% support: Apriori's runtime surges by 141.7× because it generates all candidate itemset combinations ($O(2^k)$) and scans the raw data repeatedly.
• FP-Growth is 5.23× faster: It builds a compact FP-Tree in memory once, extracting rules without generating candidate combinations.
